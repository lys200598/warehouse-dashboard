### 任务背景

将机器人运行态 `Execution` 与 Warehouse100 静态知识图谱中的 `WarehouseTask` 关联，形成“计划任务 → 机器人执行 → 状态与事件”的可追溯闭环。

### 关键结论

- 运行态写入器新增可选 `dataset_id`；只有显式设置静态数据集 ID 才建立关联。
- 写入时按相同 `task_id` 匹配 `(:Dataset)-[:INCLUDES_TASK]->(:WarehouseTask)`，并创建 `(:Execution)-[:EXECUTES]->(:WarehouseTask)`。
- 若任务来自旧 CSV 或数据集 ID 错误，匹配不到时不创建关系，不会污染静态图谱。
- 当前生成的 day1 包数据集 ID 为 `dataset:warehouse100-generated-day1-v1:2026-10-27`。
