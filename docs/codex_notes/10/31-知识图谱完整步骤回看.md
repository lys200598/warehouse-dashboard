# 知识图谱完整 Step 回看

## 任务背景

为仓储知识图谱工作台增加参考 LaDe 时间轴的回看控制器。用户应能在已完成、已落库的跨机器人 Step 之间切换，并使用同一个时间锚点查看任务、机器人、全局协同和运行态信息。

## 关键结论

- 新增完整 Step 列表读取接口，只返回单个 Run 最近最多 500 个 `Step.complete=true` 的元数据，不返回 AgentState 全量数据。
- KG 页面新增“上一完整 Step / 下一完整 Step / 回到最新”按钮和滑块；滑块按真实落库 Step 排列，不假设 tick 连续。
- 拖动滑块只更新当前选择；释放滑块或点击按钮时，才对已填写的任务、机器人、全局记录和运行态面板发起有界只读查询。
- 所有回看请求继续以 `run_id + tick` 限定。任务和机器人直接传 tick；全局统计、协助和事件在前端限制为不晚于该 tick 的记录。
- 4173 深链接带来的 tick 会作为回看的优先初始位置；若该 tick 不是完整 Step，则回退到其此前最近的完整 Step。
- 未修改仿真推进、主进程派单、机器人 Actor、全局写入服务和 Neo4j 写入逻辑。

## 后续建议

1. 重启 4173 后，打开 KG 页面，确认控制器显示完整 Step；从 4173 跳转时确认链接 tick 能定位到同一或此前最近完整 Step。
2. 选择任务和机器人后拖动滑块，确认任务时间线、机器人上下文、全局协同与运行态的 tick 一致。

4. 如果单个 Run 的完整 Step 超过 500，后续可增加“加载更早 Step”的分页，而不是提高默认返回量。
