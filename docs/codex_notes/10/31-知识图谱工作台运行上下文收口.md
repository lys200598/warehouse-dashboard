# 知识图谱工作台运行上下文收口

## 任务背景

用户要求继续优化仓储知识图谱工作台，但不增加复杂功能；重点是消除重复输入并改善空状态与失败状态的可操作性。

## 关键结论

- KG 页面只保留一个顶部“当前 Run ID”输入框，作为完整 Step、任务、机器人、运行态和全局记录查询的共同上下文。
- Run ID 可从 4173 的跳转参数或 `/api/snapshot` 自动带入，也可以手工填写历史 Run。
- 运行态和全局记录区域不再重复要求输入 Run ID。
- 没有 Run、没有完整 Step、没有 AgentState 以及 Neo4j 查询失败时，页面会提示可执行的检查方向。
- 未增加新的接口、图谱写入、仿真逻辑或全库查询。

## 执行过的操作
