# 运行态图谱模型收敛

## 任务背景

根据图谱读写评审，修正运行批次与数据集溯源、AgentState 查询键、多数据集任务定位和非采样 tick 的执行事件遗漏问题。

## 关键结论

- 新 Run 现在会保存 `dataset_id`，并建立 `(:Run)-[:USES_DATASET]->(:Dataset)`；数据集身份优先使用启动参数，未提供时从任务 CSV 同目录的 `manifest.json` 自动推导。
- `AgentState` 新增冗余 `run_id` 属性；回放查询改为 `run_id + tick`，与 KG 的时态查询键保持一致。
- 运行态增加 `AgentState(run_id,tick)`、`AgentState(robot_node_id,tick)`、`Execution(run_id,task_id)`、`RuntimeEvent(run_id,task_id)` 索引。
- 图谱任务读取会使用配置的数据集范围，Execution 同时保存 `dataset_id`，避免同名 Task 在多数据集下串联。
- 即使事件发生在非状态采样 tick，也会创建或更新对应 `Execution`；完成、取货、分配事件分别写入生命周期 tick 和状态。
- 新写入不再创建与 `Execution-[:ASSIGNED_TO]->Robot` 重复的反向 `ASSIGNED/CARRYING/COMPLETED` 关系；Execution 的生命周期改由状态属性和 RuntimeEvent 表达。
