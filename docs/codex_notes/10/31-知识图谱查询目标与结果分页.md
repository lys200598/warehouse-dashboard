# 知识图谱查询目标与结果分页

## 任务背景

用户要求从 LaDe 迁移必要的查询工作台能力，而非复制页面。目标是在仓储 KG 页面明确预置查询的目标与安全边界，并改善较多结果行的浏览体验。

## 关键结论

- 查询区会显示当前 Run、完整 Step/tick、只读预置查询边界和浏览器最多浏览 200 行的限制。
- 查询目标随当前 Run 或 tick 变化而更新。
- 查询结果支持每页 25、50、100、200 行和上一页/下一页浏览。
- 分页仅限制浏览器渲染，不改变后端 Cypher 扫描或既有接口范围；页面明确保留此前 200 行的上限。
- 没有开放任意 Cypher，仍保留 JSON 导出与当前会话内查询历史。
