# 知识图谱工作台选择引导优化

## 任务背景

用户指出回放页面中的下拉框虽然可用，但用户不知道应选择哪个对象；随后要求用同一标准优化知识图谱工作台的 Run、Step、任务和机器人选择入口。

## 关键结论

- Run ID 输入框新增最近使用 Run 候选；当前 Run 会自动写入浏览器本地最近记录，手工历史 Run 仍然可输入。
- 任务候选从 10 条扩为最多 30 条，并支持按任务 ID、货物、起点、终点、状态或机器人筛选。
- 任务按钮会显示状态和负责人，当前选择的任务具有明确高亮。
- 机器人输入改为来自当前完整 Step 的下拉候选，选项显示 `HR 编号｜阶段｜电量｜当前任务`，并优先推荐作业中机器人。
- 机器人候选、任务候选均复用已有只读接口；未新增图谱写入或调度调用。
- 补充完整 Step 与高级预置查询 tick 的时间上下文说明，以及有界关系图的节点颜色图例。
