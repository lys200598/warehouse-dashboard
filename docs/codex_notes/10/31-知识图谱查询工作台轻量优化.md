# 知识图谱查询工作台轻量优化

## 任务背景

用户要求检查并优化仓储知识图谱页面，但只参考 LaDe 已有的轻量查询工作台能力，不继续增加复杂图算法、任意 Cypher 输入或新的仿真链路。

## 关键结论

- KG 页面现在会将 URL 参数或 `/api/snapshot` 中的当前 Run ID 自动同步至任务、机器人、运行态和全局记录查询区。
- 预置查询结果由原始 JSON 文本改为字段表格展示，JSON 导出继续保留用于排查与留档。
- 新增当前页面会话内最近 20 次成功预置查询历史，记录查询类型、Run/tick、后端耗时、端到端耗时与执行时间。
- 刷新页面会清空查询历史，不增加数据库节点、关系或持久化写入。
- 仍然只调用已有预置只读查询接口，不开放任意 Cypher，与 LaDe 的“查询工作区”信息组织方式对齐但保持当前项目安全边界。
