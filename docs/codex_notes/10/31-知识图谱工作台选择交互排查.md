# 知识图谱工作台选择交互排查

## 任务背景

用户指出 14185 回放页的下拉选择缺少明确指引，并要求用同样标准排查知识图谱工作台中所有对象选择入口。

## 关键结论

- KG 页面主要问题是选择语义不足，而非缺少图谱查询功能。
- 当前 Run ID 是纯文本输入，直接打开 KG 页面时用户不知道可填写哪些历史 Run。
- 机器人查询默认值为 `1`，没有说明该机器人是否在当前 Step 有任务、状态或事件。
- 任务区只列出前 10 条按钮且没有选中样式、搜索或“当前任务”提示。
- Step 滑块与性能验证区的手工 tick 输入共存，但没有明确“完整 Step”与“手工查询 tick”的优先关系。
- 有界关系图的节点颜色没有图例，首次使用者无法快速理解 Task、Robot、Execution、Event、Handoff 的颜色含义。

## 执行过的操作

## 后续建议

1. 优先增加“最近 Run / 当前运行”候选选择，保留手工输入历史 Run。
2. 将机器人选择改为带状态的候选项，例如 `HR-023｜搬运中｜TASK-xxx`，默认选择当前完整 Step 中非待命机器人。
3. 为任务列表添加当前选中态和按任务 ID 的轻量搜索；默认突出当前执行中任务。
4. 将 Step 作为唯一默认时间上下文；把手工 tick 标为“高级查询覆盖”，避免误认为两个时间选择器独立生效。
5. 为关系图增加节点颜色图例和“当前高亮对象”说明。
