# 面向新同学的仓库设计与运行指南

### 任务背景

用户要求把已验收仓库布局、调度和仿真提交到fork分支，并附带一份面向有计算机基础、但没有项目背景的同学的详细Markdown。本子任务只负责编写指南；Git分支、选定文件、冻结源码与数据拷贝、实际启动复核由根任务处理。

### 关键结论

- 新建 `docs/WAREHOUSE_DESIGN_GUIDE.md`，先给阅读路线，然后从仓储流程逐步讲到算法、源码、数据交接和启动。
- 内容覆盖90×76m、4列×9排36架1728货位、100物理泊位与P/C别名、西IN东OUT及每IN6件暂存、库存守恒、运输能耗、低电互助、匹配保护与路径预约恢复。
- 用平实中文解释仿真、调度、SOC、SIPP、原子替换、LRU、SHA-256和P99等术语，提供小地图、货物流转示例和模块对应表。
- 明确V5中央确定性100机器人实体与原local/Ray服务的各自入口，原相机交互保持左键旋转、右/中键平移、滚轮缩放。
- 明确已验收仓库无需因本轮查询优化重做；访问层/压测与后续按需知识决策接口可单独推进。文档主体聚焦仓库，当前新查询实现不加入本次仓库提交。
- 具体命令来自实际源码：`ops/warehouse_v5_release.py`、`backend.scheduling_v5.runner`、`backend.scheduling_v5.web`、`backend.wide.scenarios`。实际文件为 `runner.py`，本项目没有 `scheduling_v5/run.py`。

### 执行过的操作

- 阅读AGENTS、V5交付及同学对接包，核对地图spec、实际货架坐标、配置继承、能量profile、互助路径、选定policy、CLI解析器及只读回放服务。
- 读取 `wide.js` 中相机函数，核对原前端交互。
- 使用本地Python `-B` 只读调用生成器、V5选定入口、V5回放入口的 `--help`，确认文档使用的命令和参数。
- 从实际 `Config()` 打印最终配置，核对100泊位、0.8m/s、10/12秒取放、35/80/20/10/25等电量配置。
- 检查相对源码链接：既有源码链接全部可解析；根任务负责提交新增对接包、样例和验收目录，使相应链接随交付一并可用。
- 本子任务没有启动远程实验，也没有写入Git、修改运行服务或更改实现文件。
