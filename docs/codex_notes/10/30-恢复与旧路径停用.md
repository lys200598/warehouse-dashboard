### 任务背景

为 C 套图谱主线停用旧主进程 A 套周期镜像，明确原生 Python AgentFleet 的弃用状态，并验证检查点恢复的机器人进程重建。准备全天分布数据和长时间测量工具。

### 关键结论

- 新增 `--legacy-a-graph` 显式开关，默认关闭 A 套镜像；SQLite journal、实际仿真帧与 C 套接口保留。
- CLI `--mode` 默认改为 `rules`，与 runtime 原默认一致。旧 `required` 历史决策依赖 A 套，必须显式启用 `--legacy-a-graph`。
- `--robot-agents` 拒绝新运行并提示改用 `--robot-processes ray`；兼容类 `AgentFleet` 标为弃用并发出 DeprecationWarning。
- 本地恢复等价测试跨越 282 步低电交接，证明旧 pool 关闭、按恢复状态重建后继续运行结果一致；真实 Ray 恢复测试按环境变量门控，首轮发现的原地回退问题见下条。
- 真实 Ray 首轮发现原地回退时，检查点未包含的未来任务仍残留已释放状态和端口绑定。已在 wz 的 `backend/wide/sim.py` 保存初始任务模板并在恢复前重建任务底表；新增 local 270→310→270→310 测试通过（9.582 秒）。此项真实 Ray 复验待执行。
- 全天数据已实际生成并通过原有严格校验：86400 秒、1728 任务，每小时 72 任务；本轮没有执行全天仿真，不声称全天验收通过。
- 图谱快照恢复仍待 wz 与 lys 确认，不实现未经确认的额外恢复入口。
