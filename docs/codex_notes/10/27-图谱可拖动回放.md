# 图谱可拖动回放

## 任务背景

参考 KG_Embodied 的帧时间线能力，在仓储知识图谱页面增加可拖动回放，使用户能从 Neo4j 已持久化的运行态数据回看指定 tick 的机器人状态。

## 关键结论

- 回放读取的是 Neo4j 中的 `Run + AgentState`，不是浏览器缓存或伪造动画。
- 页面启动后使用当前后端 Run 查询图谱写入进度，并以已写入的最新 tick 作为滑块上限和初始位置。
- 拖动滑块时只更新标签；释放滑块、键盘确认或点击前后 tick 按钮时才向后端请求，避免对 Neo4j 产生逐像素查询负担。
- 回放图显示该 tick 的机器人相对位置、提示信息和执行/待命统计；颜色区分充电、待命与其他执行状态。
- 未开启运行态写入、没有对应 Run 或不存在 AgentState 时，页面会明确提示“回放未就绪”。
