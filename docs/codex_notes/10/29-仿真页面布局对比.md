# 仿真页面布局对比（wz vs 当前 4173）

## 任务背景

用户要求对比 `wz/warehouse-design` 分支的仿真页面布局与当前 4173 页面的差异。本文对比两边的 HTML/CSS/JS、实际运行服务和场景规格。

## 关键结论

- 两边共用同一套三栏控制台骨架：顶栏、四张指标卡、左侧机器人集群、中间仓库态势、右侧设备详情/任务队列、底部运行状态。
- **最大差异是地图布局与运行源**：
  - `wz` 的 14186 实时页直接渲染 V5 真实场景：90×76m、36 架货架、1728 货位、8 列/面、100 泊位。
  - 当前 4173 通过 `/api/layout` 渲染扩展布局：100×90m、40 架、1920 货位、8 列/面；但底层仍是旧 32×22 控制仿真（15 架、540 货位），机器人/任务坐标靠 `mapLegacyPoint` 映射。
- 因此当前页面是**扩展布局外观 + 旧控制坐标**的混合体；wz 页面是 V5 原生坐标与轨迹，不存在映射层。
- 当前页面的头部/底部文案仍写“32 × 22 单元 · 6 列 × 前后 2 排”“坐标单位 0.5m”“场景版本 WH-01.4”，与实际渲染的 1920 货位扩展布局不一致。
- 控件差异：
  - wz 有“固定数据集”下拉框、`单步1秒`、`保存检查点`、`保留记录，另开新run`。
  - 当前 4173 没有数据集选择/单步/保存检查点/新 run；保留播放/暂停、倍速、重置、优先任务、新增 100 单。
- 知识查询：wz 集成在页面底部 `SHARED KNOWLEDGE / 共享知识与历史查询` 面板；当前拆成独立的 `kg.html`，顶栏提供“知识图谱工作台”链接。
- 顶栏：当前有“知识图谱工作台”和“回放页面”两个额外链接；wz 顶栏没有。
- 指标卡：当前保留装饰性 sparkline、“今日完成/较上一时段”；wz 去掉装饰曲线，使用“累计完成/固定数据集”和 `—` 占位，强调真实后端。
- 运行数据：当前 4173 是 `warehouse-3fafa0f3f4cb`（旧协调器、CSV 日包、tick 约 1.6 万）；wz 14186 是 `wh-live-...`（V5 live、required/Neo4j、seven-patterns、elapsed 约 23.5 万、60×）。

## 后续建议

1. 先明确产品方向：4173 是要继续“扩展布局外观 + 旧控制映射”，还是切到 wz 的 V5 真实 90×76 页面。两者不能长期混用。
2. 若保留扩展布局，应把头部/底部文案、坐标单位、场景版本改成实际布局值，并移除映射层。
3. 若采用 wz 页面，应迁移 `original-platform.mjs`、数据集选择、单步/保存/新 run 和底部知识查询，并让 4173 运行源切到 V5。
4. 当前页面与 wz 的顶栏链接、指标卡装饰、知识查询位置差异，建议在统一入口时一并收敛。
