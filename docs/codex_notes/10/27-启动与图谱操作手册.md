# 启动与图谱操作手册整理

### 任务背景

用户要求在仓库根目录提供一份可直接交接的操作文档，包含项目 Java 环境、独立 Neo4j、测试数据生成、静态知识图谱导入、运行态写入和服务启动命令。

### 关键结论

- 新手不需要 LaDe、KG_Embodied 或 `sudo` 权限即可按项目内路径完成配置。
- Java 运行时固定为项目虚拟环境中的 Java 21，Neo4j 固定为项目 `.runtime` 下的独立实例。
- 静态图谱使用 `current-layout-day1` 数据包，必须与后端的 `--dataset-path` 保持一致。
- 百万运行态 JSONL 仅用于规模数据导入，与真实仿真运行态数据分开说明。
- 文档明确使用独立的 `47474/47687` 端口，避免与 KG/LaDe 实例冲突。

### 执行过的操作

- 阅读既有 Neo4j 双实例部署手册、README、数据生成/导入脚本与后端参数。
- 使用脚本 `--help` 核对数据生成、静态导入、百万运行态生成和后端启动参数。
- 未启动、停止、重置或写入任何 Neo4j 服务。
