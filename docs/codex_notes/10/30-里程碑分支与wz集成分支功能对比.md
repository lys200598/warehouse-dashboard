# 里程碑分支与 wz/integration-on-lys 功能对比

## 任务背景

用户确认当前 `integration/lys-wz-261030` 是里程碑版本，需要与 `wz/integration-on-lys` 进行功能级对比，明确当前分支相对协作者集成分支新增的能力、保留的能力和仍未完成的边界。

## 关键结论

- 两分支共同基线为 `e30af3a`；当前分支比 `wz/integration-on-lys` 多 4 个提交，HEAD 为 `6f25b4b`。
- `wz/integration-on-lys` 已具备 120×90 medium 布局、48 货架/2304 货位、V5 实时服务、100 个 Ray 运动 Actor、可选机器人自主子图写入和实时页面。
- 当前分支新增 `backend/global_writer.py`：以独立普通子进程写全局图谱事实，补齐 Ray 机器人各自写子图时缺失的调度全局视角。
- 当前新增 `RunStat`、`DispatchState`、`Assist` 与全局 `RuntimeEvent` 节点及对应查询 API/UI，KG 工作台不再只能观察单机器人状态。
- 当前把 `config/live-wheeled-datasets.json` 的 medium 输入显式绑定到静态图谱的 canonical Dataset ID，修复了运行态 `Execution` 不能稳定关联 `WarehouseTask` 的风险。
- 当前任务追溯按 `runId` 限定执行记录和事件，避免同一 `task_id` 跨不同运行批次混查。
- 当前分支将 120×90 medium 作为唯一新实验主基准；旧 90×76/1728 布局仅保留历史对照，默认静态图谱导入也切换为 medium 数据包。

## 执行过的操作

- 执行 `git log --oneline --decorate` 比较两分支的最近提交。
- 执行 `git merge-base integration/lys-wz-261030 wz/integration-on-lys`，得到共同基线 `e30af3a`。
- 执行 `git diff --stat`、`git diff --name-status` 和关键模块的统一 diff。
- 阅读当前 `README.md`、`ops/warehouse_live.py`、`ops/warehouse_live_runtime.py`、`backend/global_writer.py`、`backend/warehouse_graph_query.py`、`backend/warehouse_runtime_graph.py`、启动脚本与数据集配置。
