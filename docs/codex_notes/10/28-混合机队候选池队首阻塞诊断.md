# 混合机队候选池的队首阻塞诊断

### 任务背景

真实1728任务高峰回归中，原全X3模型保持4179秒、平均380.68秒、0迟到；40/40/20混合机队约7036秒、平均1341秒，858条迟到（主任务提供，本文未独立在线复算）。主任务要求只读诊断是否存在32条候选池被高层任务占满、导致短臂型号闲置，并保留所有不利结果。

### 关键结论

- 已用真实100机器人移动、预约、能量和取放流程复现候选池队首阻塞：80条L3任务排在20条L1/L2任务前，10秒时60条L3仍ready，候选32条全L3；40台A1和40台R2全部空闲，低/中层任务已ready却直到254秒才第一次派发。
- `capability_spare_cost_seconds`从15增至150不能让池外任务进入候选；首低层派发仍为254秒。软代价只处理池内可见任务的型号选择。
- 分型号补池能提前派发低层任务，并降低这个样例的平均流转，但本轮所有研究变体均增加总完成时间。没有形成符合主任务“不退化”条件的小补丁，未改动v1或v2核心。
- 直接按EDF只取20条L3不等价于原32池中通过成本匹配选20条；会改变空间/任务选择。即使先保留原32池的派单再补池，新增并发运输也会改变后续交通与预约，不能从静态可行性推导整体时间改善。
- 40/40/20还存在真实高层运力约束；需要以完整1728任务和全货架覆盖的混合50对照决定型号比例。该小样例只用来定位机制，不作为正式负载或最终机队选型依据。
- 已停止进一步配额试探；以下全部结果与输入均保留，未修改截止时间、过滤失败样本或改规划/交通算法。
