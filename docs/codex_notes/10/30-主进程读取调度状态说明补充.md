# 任务背景

用户要求不新增根目录说明文件，而是在既有《全局记录服务主进程接入说明》中补充主进程读取调度状态的交接内容，供协作者接入绿色箭头“Neo4j → 主进程”。

## 关键结论

- 读取调度状态应以 `Run.latest_step` 指向的完整 `Step` 为唯一全局一致读点。
- `RuntimeEvent` 或单台机器人 `AgentState` 的最大 tick 可能是部分帧，不能作为恢复和派单依据。
- 14284 已提供最近完整帧、指定帧和按帧读取机器人状态的 HTTP 接口。
- 主进程仍然负责库存、交通预约、任务队列与下一轮派单；图谱用于恢复和校验。
- 写入请求返回 `202` 仅说明记录入队，读取端需要处理异步落库的短暂延迟。

## 执行过的操作

- 读取根目录 `全局记录服务主进程接入说明.md` 的现有写入协议。
- 在该文件补充绿色箭头的读取链路、接口表、Python 示例、数据责任边界和异常处理规则。
- 未启动 Neo4j、14284、Ray、4173 或测试命令。
