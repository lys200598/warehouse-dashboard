# 机器人持货行走速度核对

### 任务背景

用户提出核对现今具身机器人的持货行走速度，评估当前 0.8 m/s 是否偏慢；主线仍为更大仓库、混合机器人能力与知识图谱的可信仿真。

### 关键结论

- 核对智元、优必选、宇树共 6 份官方产品页/技术文档，未取得完整的指定负载持续搬运速度数据。
- 智元官方列出 A2 Ultra 最高 1.2 m/s、A2 Lite 最高 0.8 m/s，臂部最大负载约 2 kg；页面未确认这些最大值能同时达到。
- Walker S2 官方确认 15 kg 双臂负载；本轮可读正文及手册参数表没有给出持货速度。宇树 H1 的 3.3 m/s 移动能力也没有同时给出持货条件。
- 保留 0.8 m/s 基线，1.0 / 1.2 m/s 作为单独保存身份的假设敏感性档位。主任务已另行完成独立的 1.0 m/s 实验，结果统一见 [本轮交付说明](../../MEETING_DELIVERY_20261028.md)，本资料调研不重复实验数值。
- 0.8→1.0 m/s 属于仿真参数敏感性，尚未完成真实硬件校准，速度与能耗的耦合也待校准。
- 加速不能直接等同于吞吐增幅；还需检查取放、等待、转弯、交通和能耗计费口径。

### 执行过的操作

- 使用网页检索并直接打开厂商官方页，具体链接和参数口径见主文档。
- 读取本地 `docs/WAREHOUSE_DESIGN_GUIDE.md` 第 4.1—4.2 节，核对移动、取放、载荷和电量模型的现有说明。
- 尝试读取 Walker S2 官方规格图，确认该图片主要是机身接口示意，未据其推算速度；临时下载位于系统临时目录，没有作为仓库运行输入。
- 本地目录不含可用 Git 元数据，资料调研子任务没有执行 Git 写入操作；也没有连接服务器或变更运行服务。主任务的独立运行记录见上述交付说明。
