## 任务背景

“查询与性能验证”结果表存在多字段记录，表头换行和字段被压缩会降低可读性。需要让结果区可横向拖动，并保证标题保持单行。

## 关键结论

- 查询结果表按内容宽度展开，表头不再换行或省略。
- 结果容器保留横向滚动条，也支持鼠标或触摸横向拖拽。
- 结果内容单元格仍允许换行，避免长 JSON 或标识字段无限拉宽单行。
- 不改变查询、分页、导出或接口返回逻辑。

## 执行过的操作

- 调整 `dist/styles.css` 中 KG 查询结果表的溢出、宽度与表头规则。
- 在 `dist/kg.html` 为查询结果容器增加 Pointer Event 横向拖拽逻辑。
- 执行 `git diff --check` 静态检查。

## 修改内容

- `dist/kg.html`：新增仅作用于查询结果区的横向拖拽处理。
- `dist/styles.css`：固定表头单行、设置表格最小内容宽度、启用横向滚动和拖拽光标。
