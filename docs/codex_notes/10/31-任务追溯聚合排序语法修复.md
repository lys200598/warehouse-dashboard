# 任务背景

4173 知识图谱管理页的“按任务追溯”报 Neo4j `Statement.SyntaxError`：聚合后的查询仍使用前一作用域变量 `e.updated_tick` 排序。

## 关键结论

- 问题来自任务追溯 Cypher 的作用域规则，不是 Neo4j 连接、数据集或运行态数据损坏。
- `collect(DISTINCT history.robot_id)` 触发聚合后，原来的 `RETURN ... ORDER BY e.updated_tick` 不合法。
- 修复后先通过 `WITH` 聚合并保留 `e`，再排序、限制和返回投影。
- 该修改仅影响有运行态 `Execution` 的任务追溯查询；静态任务、Step、机器人状态和写入链路不变。

- 使用 Git blame 确认错误来自既有 LYS 追溯查询，而不是协作者此次 Actor 集成。
