# 100 台人形机器人仓储调度台

这是一个纯前端可交互原型，用于展示 100 台轻量人形机器人在多层货架仓库中执行取货、搬运和上架任务。

## 查看页面

直接用浏览器打开 `dist/index.html`，或在本目录运行：

```bash
python3 -m http.server 4173 --directory dist
```

然后访问 `http://localhost:4173`。

页面不依赖 npm 包、CDN 或后端服务。

## 已实现

- 100 个独立机器人状态机；
- 前往取货、取箱、携箱移动、抬臂上架、返回和充电；
- 2.5D 透视视图与俯视图；
- 三层低位货架、层级筛选、路径显示和拥堵热力图；
- 基础型、增程型和长臂型机器人，具有不同最大放置高度；
- 两段式伸缩臂上架动画（外臂、内伸缩杆与夹爪同步抓箱），并按机器人的可达层自动分配任务；
- 完成后的货物持续保留在目标格位；
- 点击机器人查看任务、电量、坐标和执行进度；
- 集群状态筛选、机器人编号搜索；
- 暂停、0.5×—4× 倍速、重置仿真；
- 插入优先任务和导出 CSV 状态。

## 文件

```text
dist/
├── index.html    # 页面结构
├── styles.css    # 调度台视觉样式
└── app.js        # 机器人进程、动画与交互逻辑
```

当前仿真全部运行在浏览器中。后续接入后端时，可以保留渲染层，将 `app.js` 中的机器人状态更新替换为 WebSocket 快照。
